# WAKEUP PRO

Smart alarm clock + brain-training games. Native Android (Kotlin, Jetpack Compose). Developer: Carfam.

## Features
- Alarms: multiple alarms, AM/PM or 24h, Once / Every day / Weekdays / Weekends / custom days, label, edit, delete, on/off switch, next-alarm card, saved locally, restored after reboot.
- When an alarm rings: loud alarm sound (alarm audio stream) + vibration + full-screen screen over the lock screen. Sound never stops until all brain games are solved. No Stop button, back button disabled.
- 28 games, 3 random different games per alarm (changeable 2-5 in Settings). Wrong answer = fresh new puzzle. No skipping.
- Stopwatch (laps, milliseconds, survives screen lock/minimize), Timer (alert sound at zero, works in background).
- Settings: volume, alarm sound, vibration, dark/light theme, difficulty (default Hard), 12/24h, number of challenges, practice mode, real 10-second test alarm, Contact Support, App Info.

## Games (28)
Original 20: Number Memory, Reverse Number Memory, Missing Number, Shape Recognition, Pattern Completion, Color Recognition, Stroop, Odd One Out, Logic Puzzle, Sequence, Word Memory, Quick Decision, Symbol Matching, Memory Grid, Mental Math, Direction, Image Matching (card pairs), Find the Different One, Brain Teaser, Reaction Test.

From the reels: Tap Challenge (taps left), Shake To Dismiss (accelerometer ring), Control Panel (target configuration + sequential tasks), Balance Test (D-pad ball, hold inside ring).

Original CARFAM games: Simon Sequence, Catch The Dots, Swipe Rules (same/opposite way), Slider Lock.

## Anti-repetition
- Every puzzle is generated by an algorithm from random parameters and gets a content-fingerprint ID.
- The last 400 IDs are stored locally; a duplicate is regenerated (up to 40 tries).
- The 3 games of an alarm never include any game used by the previous alarm, so the combination never repeats in consecutive alarms.
- Difficulty adapts slowly: flawless alarms push it up, many mistakes push it down (never above/below the Easy..Hard range).

## Build the APK from your phone (GitHub Actions)
1. Create a new GitHub repo and upload the full contents of this folder (keep the `.github/workflows/build-apk.yml` path).
2. Open the repo -> Actions -> "Build APK" -> Run workflow (it also runs on every push to main).
3. When it finishes, download `app-debug.apk` from Releases (or from the run's Artifacts) and install it.

Build on a computer instead: open the folder in Android Studio and press Run, or run `gradle assembleDebug`.

## Permissions to allow after install
- Notifications (Android 13+), Full-screen alarm (Android 14+), Battery -> Unrestricted. The Alarm tab shows buttons for anything still missing.
- Xiaomi / Oppo / Vivo / Realme / Samsung / OnePlus: also enable Autostart and remove battery limits for WAKEUP PRO.

## Android limits (honest notes)
- If you force-stop the app (Settings -> Apps -> Force stop), Android cancels its alarms until you open the app again. No app can avoid this.
- Alarms use `AlarmManager.setAlarmClock`, which is exact, Doze-exempt and survives reboot (re-armed by a boot receiver).
- If the phone is unlocked and you are in another app, Android shows the alarm as a heads-up notification; tap it to open the challenge (opening WAKEUP PRO also jumps straight to the challenge while an alarm rings).

## How to test
Settings -> "Practice a brain challenge" (no sound) and "Ring a real test alarm in 10 s" (lock the phone / minimize the app to test background behaviour).

```
  util/                      Permissions helpers, sound preview
```
